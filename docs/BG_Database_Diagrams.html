BG Automation — Database Diagrams (SQLite)

Conceptual ER (key attributes, crow's foot) followed by the full logical schema. Table design matches db/sqlite/schema.sql; seed values match db/sqlite/seed.sql. One BG row per guarantee, dedupe on bg_no; extensions chain via supersedes_bg_id under the same loa_id (1 LOA : M BGs).
